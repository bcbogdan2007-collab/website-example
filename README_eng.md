# 🌐 Bogdan — Developer Portfolio Website

A single-page **personal portfolio website** for a **Python developer**, presented as a clean, modern landing page in one self-contained `index.html` file — no build tools, no dependencies.

The site showcases the developer's projects, services, and working process, and provides a direct way to get in touch. All content is fully bilingual (RU/EN) and switches dynamically in the browser.

## What It Shows

- **Hero section** — a short introduction with a stylized “developer profile” card containing a mini code snippet and key highlights;
- **Projects** — four demo projects: a barbershop booking bot, a Telegram clothing shop, a Gemini AI assistant, and a responsive portfolio website, each with an icon, description, tech tags, feature list, and a live link;
- **Services** — six areas of work: Telegram bots, simple websites and landing pages, Python scripts and automation, shops and catalogs, API & AI integrations, and small utilities;
- **Process** — a three-step workflow from brief to launch;
- **Contact** — a prominent call-to-action block with a direct Telegram link.

## Highlights

- bilingual content (RU / EN) with one-click switching;
- responsive layout that adapts to phones, tablets, and desktops;
- modern styling with a soft color palette, cards, and subtle hover effects;
- semantic, accessible markup with smooth scrolling;
- fully static — works offline and can be hosted anywhere.

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (custom properties, Grid, Flexbox, `clamp()`, media queries)
- Vanilla JavaScript (language switching, auto-updating year)

## Purpose

The site serves as a **portfolio and presentation page** for a Python developer: it introduces the person, demonstrates sample projects, describes available services, and invites visitors to start a conversation in Telegram.
